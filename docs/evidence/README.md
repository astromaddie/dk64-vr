Unattended eye and panel dumps from the Steam Frame (headset off-head, `force_render`, synthetic head),
downscaled. Not acceptance: nobody has worn these builds.

- `dk-isles-yaw0-left/right`: DK Isles, 2160² per eye, stereo pair (asymmetric eye frusta, so the two
  images are offset as well as in parallax).
- `dk-isles-yaw90-left`, `dk-isles-yaw180-left`: the same spot with the synthetic head turned 90 and
  180 degrees (1728² per eye); the sky dome and the geometry behind the game camera are there.
- `panel-file-select`: the flat panel (RT64's VI output, 4:3 in 16:9) at the file select.
